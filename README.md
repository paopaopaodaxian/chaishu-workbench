# 拆书工作台

一个在你自己电脑上运行的网文拆书工具。它调用你本机已经登录的 **Claude Code** 或 **Codex**，把小说逐章拆成「开场期待、人物目标、冲突推进、情绪回报、章尾牵引、可迁移写法」等结构分析。**每条结论都标出它依据的是原文哪一段**，点一下就能跳到原文核对。

适合想系统研究别人怎么写、再用到自己作品里的网文作者。

![分析阅读器：左侧章节，中间结论，右侧原文依据](docs/screenshots/reader.png)

## 它能做什么

- **导入整理**：导入 TXT（自动识别 UTF-8 / GBK / Big5，能识别出乱码），自动切分章节。支持合并、拆分、重命名章节，也可以排除广告段。
- **三种拆解方法**：内置「开篇研究」「逐章结构」「婚恋专项」，可以复制后改成你自己的问题清单。
- **分析范围**：前三章、指定章节或全书。长篇会先逐章分析，再分段汇总、全书汇总，不会把百万字一次塞给模型。
- **有据可查**：模型必须引用段落编号（如 `2-18` 表示第 2 章第 18 段），程序会逐条校验编号是否真实存在。找不到依据的结论会被明确标出来。
- **人工核对**：每条结论可以标「已核对 / 有疑问」，写备注，直接改写（原输出保留），也可以针对某条疑问让模型重新分析这一章。
- **多书比较**：2–6 本书并排对照。每一格结论都能追溯到具体书、具体章节。
- **任务可恢复**：可以暂停、继续、失败重试；断网、额度用完、电脑重启后，已完成的部分都会保留。
- **导出与备份**：报告可导出为 Markdown / JSON，整个书库可以一键备份和恢复。

## 使用前准备

1. 一台 Mac（Apple 芯片或 Intel 都可以）。
2. 至少装好并登录以下一个工具，并且在「终端」里能直接运行：
   - [Claude Code](https://docs.claude.com/en/docs/claude-code/overview)（运行 `claude`）
   - [Codex CLI](https://github.com/openai/codex)（运行 `codex`）
3. Python 3.9 或以上。macOS 一般自带；如果提示缺少，在「终端」运行 `xcode-select --install`。

分析时用的是你自己的账户和额度，本工具不经手、也不保存任何账号密码。

## 安装

1. 到本页右侧的 **Releases** 下载最新的 `拆书工作台-x.x.x-macOS.zip`，双击解压。
2. 把「拆书工作台」拖进「应用程序」文件夹。
3. **第一次打开**：这个应用没有经过苹果的付费签名，第一次双击时 macOS 会拦截。按下面的方法处理一次，以后就能正常双击：
   - 先双击一次，看到提示后点「完成」或「取消」；
   - 打开「系统设置 → 隐私与安全性」，在页面下方找到关于「拆书工作台」的提示，点「仍要打开」；
   - 较旧的 macOS 也可以直接在应用上按住 Control 键点按（或右键）→「打开」→「打开」。
4. 打开后浏览器会自动显示工作台页面（地址是 `http://127.0.0.1:8765`）。

用完点左侧栏底部的「关闭工作台」。下次使用再双击应用即可，数据都会保留。

## 基本流程

1. **导入小说** → 检查编码和预览 → **确认目录**（目录确认后才能分析）。
2. **新建分析**：选范围、拆解方法和模型，预览会显示要处理多少章、多少字、调用多少次。
3. 在「任务」里看进度。已完成的章节可以先看，不用等全部跑完。
4. 在**分析阅读器**里点结论下面的段落编号，右侧会显示并高亮原文，然后逐条核对。
5. 有了几本书的报告后，到「多书比较」里对照。
6. 导出 Markdown 报告，或在「设置」里备份整个书库。

## 数据存在哪里

- 书库、报告、核对记录：`~/Library/Application Support/拆书工作台/data`
- 运行日志：`~/Library/Application Support/拆书工作台/server.log`

所有数据只保存在你的电脑上。只有你点「开始分析」时，选中的正文才会发送给你选择的模型服务（Anthropic 或 OpenAI）。导出的报告默认不包含原作全文。

## 常见问题

**设置页显示某个工具「未安装」或「未连接」**
先在「终端」里运行 `claude` 或 `codex`，确认能用并已登录，然后在设置页点「验证连接」。如果终端里能用、应用里却找不到，把 `server.log` 的最后几行发到 Issues。

**提示端口被占用**
多半是之前在终端里用 `python3 server.py` 启动过一份，先在那个终端按 Ctrl+C 关掉。

**分析中途显示「等待额度」或「需要重新登录」**
工具不会自动重试这两类错误，以免浪费额度。处理好后在任务页点「继续」，已完成的章节不会重新跑。

**能在 Windows / Linux 上用吗？**
没有打包好的应用，但可以从源码运行（见下文）。

## 从源码运行（任何系统）

```bash
git clone <本仓库地址>
cd <仓库目录>
python3 server.py
```

然后打开 http://127.0.0.1:8765 。没有任何第三方依赖。用 `PORT=8800` 可以换端口，用 `NOVEL_DATA=/某个目录` 可以指定数据位置。

## 项目结构

```
server.py            本地 HTTP 服务与接口
core/engines.py      Claude Code / Codex 适配：登录、身份识别、调用、错误分类
core/analysis.py     分析范围、工作单元、提示词、段落依据校验、多书比较
core/worker.py       顺序任务队列与状态机（暂停 / 恢复 / 重试 / 中断恢复）
core/textproc.py     编码检测、切章、目录编辑、正文版本
core/templates.py    拆解方法与版本
core/reports.py      报告、导出、备份恢复
core/db.py           SQLite 数据存储
static/              网页界面
macos/               macOS 应用的启动器、图标和 Info.plist
scripts/             打包脚本
```

打包 macOS 应用：`scripts/build_macos_app.sh 0.1.1`。

发布新版本：修改 `VERSION` 文件里的版本号并推送到 `main`，GitHub Actions 会自动打包并创建对应的 Release。

## 使用须知

- 请只分析你有权使用的文本，不要把受版权保护的原文或包含大量原文的报告再公开传播。
- 使用 Claude Code / Codex 时，请遵守 Anthropic 和 OpenAI 各自的服务条款。
- 分析结果是模型对文本的解读，「证据充分 / 有限 / 不足」只是分析标签，不是统计置信度；请以原文核对为准。工具不会、也无法预测作品的商业表现。
